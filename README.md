# ⚔️ Тень Клинка

**«Тень Клинка» — поединки теней** — офлайн-файтинг на мечах в духе Shadow Fight 2: силуэты бойцов, удары мечом и ногой, блоки, выпады, подсечки и серии ударов. Вся игра — один HTML5-файл (`index.html`) без интернета и внешних зависимостей; Android-версия — это нативная обёртка (WebView) вокруг того же файла.

- 📱 **Android APK:** [скачать ten-klinka.apk](https://github.com/LuntikVisuals/ten-klinka/releases/latest/download/ten-klinka.apk) (раздел [Releases](https://github.com/LuntikVisuals/ten-klinka/releases))
- 🌐 **Играть в браузере:** https://luntikvisuals.github.io/ten-klinka/ (если включены GitHub Pages) или просто откройте `index.html`

## Установка на Android

1. Скачайте `ten-klinka.apk` по ссылке выше на телефон.
2. Откройте файл. Android попросит разрешить установку из неизвестных источников — разрешите для браузера / файлового менеджера («Настройки → Безопасность → Установка неизвестных приложений»).
3. Нажмите «Установить» и запускайте «Тень Клинка». Игра работает без интернета, в горизонтальном полноэкранном режиме.

Требования: Android 7.0 (API 24) и новее. Пакет: `com.luntikvisuals.tenklinka`.

## Управление

**Сенсорный экран**
- Слева — джойстик: ◀▶ ходьба, ▲ прыжок, ▼ присед.
- Держите **назад** — блок (назад + ▼ — нижний блок).
- Справа — кнопки **«Удар»** (меч) и **«Нога»**.
- Вперёд + Удар — выпад, ▼ + Удар — подсечка, ▲ + Удар — удар сверху, Удар ×3 — серия.

**Клавиатура (браузер)**
- ← → / A D — ходьба, ↑ / W / Пробел — прыжок, ↓ / S — присед, назад — блок.
- J / Z — удар мечом, K / X — нога, P / Esc — пауза.
- Вперёд + J — выпад, ↓ + J — подсечка, ↑ + J — удар сверху, J J J — серия, ↓ + K — подсечка ногой.

## Сборка из исходников

Исходники Android-приложения — в папке [`android/`](android/) (Java, один WebView-Activity, minSdk 24, targetSdk 34). Игра копируется из корневого `index.html` в assets автоматически.

```bash
cd android
./gradlew assembleRelease   # нужны JDK 17 и Android SDK 34
```

Для подписанной сборки создайте `android/keystore.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`) — он в `.gitignore`, ключ подписи в репозиторий не добавляется.
